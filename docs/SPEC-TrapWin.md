# TrapWin Sample – zadání (navazuje na Digga Killa)

- Design podle webu trapwin.com.
- Do pluginu se dá song nebo loop (WAV, MP3). Plugin najde začátky 8 nebo 16 taktů, tedy místa, kde třeba začíná kick nebo melodie, a z celého songu vytvoří několik ukázek: 8 a 16taktové loopy a one-shot zvuky.
- One-shoty nesmí být náhodné: plugin ví, jak začíná melodie, nebo kde je uprostřed melodie one-shot zvuk použitelný na beat.
- Kliknutím na vzorek se otevře obrazovka pro editaci, kde se s ním dál pracuje.
- Vzorky jdou kdykoli přetáhnout do DAW (FL Studio, Ableton apod.).
- Rozložení: vlevo vinyl pro přetažení songu, vpravo loopy a zvuky, pod tím obrazovka pro editaci samplu.
- Název: TrapWin Sample. Verze pro Windows a Mac, včetně podepisování pro Mac.
